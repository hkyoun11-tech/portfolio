무엇을 재나결과적 징후(심박, 활동량)사용자가 직접 입력원인적 행위(섭취 속도, 염도)
언제 개입하나사후 분석과 알림사후 분석과 피드백식사 중 실시간 진동
쓰기 편한가착용만 하면 됨매번 입력해야 함평소처럼 식사만 하면 됨

팔리게 만드는 설계

  • 가격프리미엄 가격대에 단수 가격(앞자리 효과)을 적용해 심리적 저항선을 낮췄습니다.
  • 유통과 홍보자사 D2C 몰과 헬스케어 플랫폼 중심으로 팔고, 건강관리 숏폼과 비만 클리닉 제휴 체험단으로 알립니다.
  • 확장기기 판매에서 식습관 데이터 구독, 병원·제약사 B2B 파트너십까지 3단계로 그렸습니다.
  • 위험 대응초기에는 개인용 웰니스 기기로 포지셔닝하고, 고가 부담은 렌탈·통신사 결합 상품으로 대응합니다.
